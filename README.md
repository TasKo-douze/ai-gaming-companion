# AI Gaming Companion

Créer une intelligence artificielle capable de jouer comme un véritable coéquipier humain dans différents jeux vidéo.

## Vision
Voir la description du repository.

## Structure
See src/ for module skeletons: core, memory, conversation, games, tasks, world, personality.

## Getting started
1. Install dependencies: `npm install`
2. Start in dev: `npm run dev` (requires configuring adapters and credentials)

## MVP
- Minecraft connection
- Chat
- Persistent memory (SQLite)
- Basic tasks: follow, collect wood, deposit items
